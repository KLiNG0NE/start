# start

Eine konfigurierbare Startseite für den Browser.

---

In vielen Browsern lässt sich eine eigene Startseite bestimmen. – Diese Startseite kann an den eigenen Geschmack angepasst werden.

### URL für Startseite: ###

```
https://kling0ne.github.io/start/
```

### Optionen ###

Die Optionen sind über das Zahnrad-Symbol (⚙️) erreichbar.

#### Hintergrundbild ####

Es kann entweder die URL zu einem Bild angegeben werden, oder es wird ein eigenes Bild geladen.

##### Standard-Einstellung #####

```
https://picsum.photos/1920/1080
```

Mit dieser Einstellung wird ein zufälliges Bild mit der Aufklösung 1920 x 1080 Pixel von [picsum.photos](https://picsum.photos/ "https://picsum.photos") geladen.

``https://picsum.photos/[Breite]/[Höhe]`` – Breite/Höhe in Pixel

#### Favoriten ####

Favoriten werden im Format ``Name | URL`` angegeben. – Ein Eintrag pro Zeile.

##### Standard-Favoriten ####

```
StartPage | https://www.startpage.com
DuckDuckGo | https://duckduckgo.com/
Qwant | https://www.qwant.com/
Ecosia | https://www.ecosia.org/
Wikipedia | https://wikipedia.org
GitHub | https://github.com
Reddit | https://reddit.com
Amazon Luna | https://luna.amazon.de/claims/home
Epic Games | https://store.epicgames.com
```
